# OG: Execution-Aligned Offline Goal-Conditioned RL

Independent implementation and audit trail for the execution-aligned multi-horizon
offline RL study. The first frozen run is limited to phases A, B, and mechanism
diagnostic phase 0 on `antmaze-large-stitch-v0`.

Large datasets, checkpoints, snapshots, and raw logs live outside Git under the
run root. This repository stores code, frozen configuration, lightweight metrics,
manifests, hashes, and reports.
